# 黄昏海滨工作室：已确认设计

## 目标

让访客同时记住艺术品味与做过的事情。主场景是一间面对海滨城市的黄昏工作室，CD 机是视觉与交互中心，一张 CD 对应一个项目。滚动是在同一空间里移动视线。

## 用户已确认

- CD 机，具有弹出、换碟、读盘的意象；统一项目模板，不给每个项目单独设计场景。
- 窗外有落日、海面和远处城市，室内有桌面、音箱和收藏架。
- 参考永井博作品的空间感、明确色块与光影关系；制作原创场景素材。
- 首屏同时出现环境、名字和一个真实项目，不以空白开场动画隐藏作品。
- 滚动路径：房间全景 → CD 桌面与项目收藏 → 报纸区 → 窗边与联系方式。
- 旧“杂谈”纳入新体系，每篇 note 是一份报纸，正文沿用原内容和日期。
- 使用 BettTer/BettTer.github.io 的 master，不另建开发分支。
- 使用文字设计方案，直接进入实现，优先节省 credit。
- 使用 Windows 98 意象的原创像素箭头、点击手形；输入区域保留文本光标，触屏不强加指针。

## 实现选择（由开发者提出）

采用 React + TypeScript + Vite，原创 SVG / CSS 分层插画，CSS 原生滚动驱动动画作为增强，不支持时提供正常静态布局。播放器的换碟状态用 React 管理。

比较过完整 WebGL 三维场景：可自由转动，但本项目只需预设视角，建模和调优成本更高；普通纵向卡片页容易交付，但空间探索感不足。因此第一版采用分层插画与滚动视差。

## 页面与行为

- 首屏使用 Young 作为可配置署名（来自旧站作者），BettTer 作为 GitHub 身份；不是要求用户重新提供已有信息。
- 首批候选项目：master-duel-ai-advisor、mikumikuLive2d、UniversalPlayer、Pin-It-Here。实现时读取公开 README 后编写准确简介；可调顺序与显隐。
- Comic Looms 只有核实后的个人贡献才进入贡献说明；不把 fork 当作原创项目。
- 项目目录可直接选择；上一张 / 下一张循环浏览；快速连续选择时最后一次选择生效，不留过期动画。
- 当前项目显示名称、简述、技术信息和 GitHub 链接，有真实截图才显示截图。
- 换碟不会改变正文滚动位置；滚动不会擅自切换项目；按钮支持键盘。
- 文章区名为“杂谈”。点击报纸打开阅读面板，显示标题、日期、完整正文；关闭回到原滚动位置与焦点，Escape 可关闭。
- 保留现有 /blog/ 日期文章地址、/blog/archives、旧资源与 atom.xml；新页锚点使用 #projects、#notes、#about，不依赖服务器 SPA 重写。
- 第一版不捏造新文章、邮箱、工作成就或数据。联系方式先使用已确认的 GitHub。
- 《瞳で抱いてて》是用户提供的音乐参考；第一版独立于音源运行，不自动播放，不把网络搜到的歌曲下载打包。

## 工程与交付

- repo: https://github.com/BettTer/BettTer.github.io；正式地址 https://bettter.github.io/。
- 本地 checkout: work/coastal-studio；当前分支 master。制作完成前只改本地，不触发现有 master Pages 发布。
- 应用源码独立放在 studio/；打包到 studio/dist。新构建资源使用 studio-assets/ 前缀，与旧 assets/ 隔离。
- 旧站在构建时合入产物；只替换根首页，新报纸区复用旧文内容，旧文链接持续有效。
- 项目数据与场景美术分离；后续加项目主要编辑 studio/src/content/projects.ts，加文章可编辑 Markdown。
- 移动端采用连续纵向构图，桌面端才增强空间移动。普通滚轮与顶部导航正常工作。
- prefers-reduced-motion 下禁用视差和换碟位移动画，仍可选项目和读文章。
- 页面不在访客浏览时调用 GitHub API，不需要后端、数据库、API Key 或付费服务。
- 发布使用 GitHub Actions 构建与 Pages artifact；旧站目前是 master 根目录直接发布，正式上线时才切换发布方式。
- 本地预览可读内容与可操作播放器是第一交付，随后整体调色、动效和兼容性。用户看过本地完成版再决定发布。

## 用户配合

第一轮只需看本地预览，指出构图、颜色、机器造型最明显的不满意之处；不需要先准备每个项目的独立图稿。署名、公开联系方式和可用音乐可稍后补充，不阻塞首版。

## 第一轮反馈修订

- CD 上一曲/下一曲控制区使用独立网格与内缩边距，所有屏幕下保持在机身内。
- 当前项目、聆听区等小字使用稳定底色与高对比文字。
- 海滨天空改为粉紫渐变、暖色太阳与蓝紫海面，保留暖色室内；参考用户提供的 Young CRT 横幅色彩。
- 加入 Music 区和用户指定的 Spotify 歌手页，展示用户提供的横幅。
- 英语 / 简体中文 / 繁体中文 / 日语切换；记住访客选择。UI 和项目简介翻译，项目名称与笔记原文保留。

## 第二轮反馈修订

项目收藏区移除重复的小 CD 机，内页只展示碟片编号、项目说明、技术信息与链接；首屏大 CD 机与选碟状态保持连通。
